HTTP‑сервис на FastAPI для работы с LLM‑агентом: генерация ответа, редактирование текста и определение типа запроса. 

## Стек

- Python 3.11+
- FastAPI
- Pydantic
- Uvicorn

## Функциональность

Сервис предоставляет три основных эндпоинта под префиксом `/api/v1/answers`:

- `POST /api/v1/answers/` — сгенерировать ответ на входной текст  
- `POST /api/v1/answers/edit` — отредактировать текст с учётом исправлений  
- `POST /api/v1/answers/type` — определить тип/категорию текста и её важность
